# Mortality Data Analysis

Analysing global mortality trends using death rate data across 19 age groups, multiple countries, and 100+ years.

## Tools used
- Python, pandas, DuckDB (SQL), matplotlib, seaborn

## Analyses
- **Infant mortality over time** 
- **Death rate by age group** 
- **Country comparison heatmap** 
- **Life expectancy via life table** 
## Key findings
- Japan has the lowest death rates of any country in 2020 across almost every age group
- Life expectancy in France collapsed during both World Wars, visible as sharp dips in the data
- The US has fallen noticeably behind other developed nations in life expectancy since 2000
